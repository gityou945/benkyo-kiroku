# изучение（勉強管理）

資格試験などの「論点」を間隔反復で復習するための、単一 HTML ファイル完結型の学習管理アプリ。
フレームワーク・ビルド不要。`izuchenie.html` をブラウザで開くだけで動作する。

## 使い方

- ローカル: `izuchenie.html` をダブルクリックしてブラウザで開く。
- GitHub Pages: このリポジトリの Settings → Pages で `main` / `root` を公開すると
  `https://<ユーザー名>.github.io/<リポジトリ名>/` からアクセスできる。
  （`index.html` は `izuchenie.html` へのリダイレクト）

## データについて

- 記録はブラウザの `localStorage`（キー `izuchenie_v1`）に保存され、**サーバーには送信されない**。
- そのため端末・ブラウザをまたいだ同期はされない。
- 機種変更やキャッシュ削除に備え、設定画面から定期的に JSON エクスポートしておくこと。
  別端末へは同画面のインポートで移行できる。

## 主な機能

- **今日**: 復習期限が来た記録を能動的想起（論点名だけ見て思い出す→メモ開示→3択評価）で復習。
- **カレンダー**: 学習日・復習予定日（確定）・この先の見込みをドット表示。
- **論点一覧**: 科目/論点名で検索、記録履歴の閲覧・編集・削除。
- **統計**: 学習時間の集計、論点別ランキング、直近28日のヒートマップ。
- **設定**: 復習間隔（既定 `3,7,30,90,180` 日）の変更、データのエクスポート/インポート/全削除。
